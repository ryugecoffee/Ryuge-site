## 2. 本番での動作確認（各機能をONにした直後）

### 発送管理：`SHOP_STAFF_EMAILS` と `COFFEE_SUBSCRIPTION_FULFILLMENT_ENABLED=true` を設定した後
1. （私）`/internal/coffee-subscription/fulfillment/work` に、ログインせずにアクセスすると **401** が返ること。404ではなく401なら、機能がONで、ログインで保護されています。宛名API（`/label/…`）も401であること。
2. （CEO）`https://ryuge.biz/admin/subscription-shipping` を開き、スタッフのメールアドレスを入力する。件名「【龍華珈琲】定期便 発送管理のログインリンク」のメールが届き、15分以内に開くとログインできること。
3. （CEO）一覧は空（契約がまだないため）で、豆の在庫表がストアの在庫数と一致していること。在庫は変わりません。
4. （CEO）登録していないアドレスでは、同じ案内が表示されるだけで、メールは届かないこと。
5. （CEO）「ログアウト」の後、同じログインリンクを開いても「すでに使われています」と表示されること。

### お客様管理：`STRIPE_PORTAL_CONFIGURATION_ID` と `COFFEE_SUBSCRIPTION_MANAGE_ENABLED=true` を設定した後
1. （私）`/coffee-subscription/account/me` に、ログインせずにアクセスすると **401** が返ること（ON、かつ保護されている）。
2. （CEO）`https://ryuge.biz/subscription/manage` で、契約のないアドレスを入力しても、同じ案内が表示されるだけで、メールは届かないこと。
3. 契約があるときの確認は、受付開始直後の最初の1件で行います（4の手順）。

## 3. 受付開始で必要な操作（最小限）

前提：発送管理・お客様管理・法定表示の確認が、すべて済んでいること。#30（送料）は2026-11-19に公開済みです。

梱包について：定期便と1〜2袋の注文は、当面レターパックライト（34×24.8cm、厚さ3cm以内）で発送します。梱包はまだ実測していないため、受付開始の条件にはしていません。そのかわり、毎回の発送前に規格内であることを確認します。厚さを超える場合は無理に送らず、レターパックプラスなどに切り替えます。

1. **（CEO・Render）** `COFFEE_SUBSCRIPTION_ENABLED=true` を追加して保存する。サーバー側の申し込み窓口が開きます。ストアにはまだボタンが出ません。
2. **（私・PR）** `SUBSCRIPTIONS_PAUSED = false` に変更するPRをマージする。ストアの申し込みボタンが表示されます。
   - 旧プランは `OLD_SUBSCRIPTION_PLANS_CLOSED = true` で別に閉じているので、再開しません。

## 4. 告知前の最初の1件

**（CEO）** ご自身のカードで申し込みます（¥3,000 の実際の決済になります）。その後、次の点を確認します。
- 確認メールが届くこと
- 管理ページにログインでき、次回の請求日と初回のお届けが表示されること
- カード変更の画面で、カードの変更と請求履歴だけが表示されること
- 発送管理に初回分が、好みのコメント付きで表示されること
- 豆を2種類選んで「発送準備」にすると、ストアの在庫が1袋ずつ減ること
- 「発送済み」にすると、在庫が確定すること

確認後、この契約を続けるか、解約するかをCEOが決めます。解約した場合、初回分の返金は提案のみで、CEOの判断で行います。

## 5. 止め方（問題があったとき）

| 止めたいもの | 操作 |
|---|---|
| 新規の受付 | Render で `COFFEE_SUBSCRIPTION_ENABLED` を削除する（申し込み窓口が即404になります）。または `SUBSCRIPTIONS_PAUSED = true` に戻すPRを出す |
| お客様管理・発送管理 | それぞれのフラグを削除する |
| 送料 | #30 を revert する |

止めても、既存の契約・決済・在庫には影響しません。Stripe での請求は続きます。
