## 1-2. 2026-11-20 の修正（消費者庁ガイドラインに合わせた文言）

- **最終確認画面**：お届け先・電話番号・カードは Stripe の画面で入力し、そこで「申し込む」を押した時点で申し込みが確定します。そのため、次の2か所の両方に必要事項をすべて表示するようにしました。
  - 当店の確認画面（`/subscription/apply`、ボタンは「決済画面へ進む（まだ確定しません）」）
  - Stripe 画面の申し込みボタン横（`submitTerms`、約680字、上限は1,200字）
- **返品特約**：最終確認画面・Stripe 画面・確認メールに次を表示します。食品のため、お客様都合の返品・交換は受け付けません。破損・不足・誤りがあれば到着後7日以内に連絡していただき、交換または返金します。
- **解約手数料**：「解約手数料・違約金はありません」と全箇所に表示します。
- **期間**：「期間の定めのない定期購入です（解約されるまで毎月続きます）」と表示します。
- **1年間の参考**：初回と、開始月から12か月分の月額の合計を、選んだ回数に応じて表示します。スキップ・回数変更で変わることも明記します。
  - 例：月2回、開始が2027年1月の場合、3,000円＋5,800円×12か月＝72,600円、お届け25回・5,000g。
- **返金**：「初回の200gを発送する前に解約された場合は、初回分3,000円を全額、お支払いに使われたカードへ返金します（解約から7営業日以内に手続きします）。発送後の解約では、初回分の返金はありません。」
  - 対象：解約した時点で、初回発送の記録が「発送予定・保留・発送準備中」のいずれかであるもの。「発送済み」は対象外です。
  - 発送準備中だった場合は、確保していた在庫を戻します。発送管理では「発送済み」にできなくなります（発送を取りやめた荷物は送れません）。
  - 自動では返金しません。返金の提案を記録し、**その場でスタッフ（`SHOP_STAFF_EMAILS`）にメールで知らせます**（契約番号と金額のみ）。CEOが確認してから、Stripe で手動で返金します。

**最終確定の前に、運用できることの確認が必要です**
- 7営業日以内に Stripe で返金する体制（通知メールを受け取る人と、返金を実行する人）。

## 1-3. メールでの解約受付（運用案・まだ表示していません）

1. **窓口**：ryugecoffee@gmail.com。件名「定期便の解約希望」。
2. **本人確認**
   - 登録したメールアドレスから届いた場合：そのアドレスにだけ返信し、管理ページのログインリンクで、お客様ご自身に解約していただくよう案内します。
   - 登録したアドレスを使えない場合：氏名・郵便番号・電話番号の下4桁を、登録内容と照合します。照合はCEOが Factory の連絡先表示で行います（閲覧は記録されます）。
3. **期限の扱い**
   - 毎月1日9時より前にメールが届いていれば、期限内の解約として扱います。
   - 店舗の作業が9時を過ぎて、その月の請求が発生してしまった場合は、その月分を全額返金し、その月は発送しません（CEO承認のうえ手動）。

   - Stripe の画面で「期間終了時にキャンセル」を選ぶか、お客様に管理ページで解約していただきます。
   - Stripe の画面で解約した場合、初回分の返金提案と「解約後の月」の記録は自動では作られません。返金の要否と発送の停止は、手作業で確認します。

## 3. 受付開始で必要な操作（最小限）

前提：発送管理・お客様管理・法定表示の確認が、すべて済んでいること。#30（送料）は2026-11-19に公開済みです。

梱包について：定期便と1〜2袋の注文は、当面レターパックライト（34×24.8cm、厚さ3cm以内）で発送します。梱包はまだ実測していないため、受付開始の条件にはしていません。そのかわり、毎回の発送前に規格内であることを確認します。厚さを超える場合は無理に送らず、レターパックプラスなどに切り替えます。

1. **（CEO・Render）** `COFFEE_SUBSCRIPTION_ENABLED=true` を追加して保存する。サーバー側の申し込み窓口が開きます。ストアにはまだボタンが出ません。
2. **（私・PR）** `SUBSCRIPTIONS_PAUSED = false` に変更するPRをマージする。ストアの申し込みボタンが表示されます。
   - 旧プランは `OLD_SUBSCRIPTION_PLANS_CLOSED = true` で別に閉じているので、再開しません。

## 4. 告知前の最初の1件

**（CEO）** ご自身のカードで申し込みます（¥3,000 の実際の決済になります）。その後、次の点を確認します。
- 確認メールが届くこと
- 管理ページにログインでき、次回の請求日と初回のお届けが表示されること
- カード変更の画面で、カードの変更と請求履歴だけが表示されること
- 発送管理に初回分が、好みのコメント付きで表示されること
- 豆を2種類選んで「発送準備」にすると、ストアの在庫が1袋ずつ減ること
- 「発送済み」にすると、在庫が確定すること

確認後、この契約を続けるか、解約するかをCEOが決めます。解約した場合、初回分の返金は提案のみで、CEOの判断で行います。
