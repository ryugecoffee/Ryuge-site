# 発送管理（通常注文・定期便）の使い方（2026-11-21）

画面：`https://ryuge.biz/admin/shipping`（以前の `/admin/subscription-shipping` も同じ画面です）
ログイン：`SHOP_STAFF_EMAILS` に登録したスタッフのメールアドレスに届くリンク（15分有効・1回限り、ログインは2時間）。新しい管理用トークンはありません。

## 通常注文タブ
対象は、Stripe で決済が完了し、Webhook で `orders/{PaymentIntent ID}` に記録された注文です。

| 状態 | 意味 | できること |
|---|---|---|
| 新規 | 決済済み、まだ手を付けていない | 発送準備中にする／発送済みにする／保留にする／宛名を表示 |
| 発送準備中 | 梱包中 | 発送済みにする／準備をやめる（新規に戻す）／保留にする／宛名を表示 |
| 保留 | 住所確認などで止めている | 新規に戻す |
| 発送済み | 発送した（取り消しはできません） | 発送メールの再送（送信に失敗した場合のみ） |

- **在庫**：通常注文の在庫は決済時に処理済みです。この画面の操作では在庫は変わりません。
- **発送できない注文**：返金済みの注文は発送できません。一部返金のある注文は、注意を表示したうえで発送できます。
- **発送の目安**：目標はご注文の翌日、期限は3営業日です（土日祝を除いて数えます）。期限を過ぎると「発送期限を過ぎています」と表示されます。
- **配送方法**：国内はレターパックライト、レターパックプラス、ゆうパック、クリックポストから選びます。海外は国際エアパケットです。閻魔 珈琲袋と木函のお茶はレターパックライトでは送れません（レターパックプラスに入ればそれを使い、入らなければゆうパック）。
- **追跡番号**：任意です。入力すると、お客様へのメールに追跡用のリンクが付きます。
- **お客様の情報**：一覧に出るのは、お名前と都道府県・市区町村までです。住所・電話番号は「宛名を表示」を押したときだけ表示され、誰がいつ見たかが記録されます。

## 定期便タブ
- これまでの定期便の発送管理と同じ画面です。在庫は「発送準備」で確保し、「発送済み」で減ります。
- 配送方法は、通常はレターパックライトです。厚さ3cmを超える場合は、レターパックプラスなどを選べます。

## 発送メール（両方のタブ共通）
- 「発送済みにする」と、お客様にメールが1通送られます。件名は、通常注文が「ご注文の商品を発送しました」、定期便が「珈琲の定期便を発送しました」です。
- 同じボタンを2回押しても、2人が同時に押しても、メールは1通だけです。
- テスト注文（Stripe のテストモードの注文）には送りません。
- 送信に失敗した場合は「発送メールを送れませんでした」と表示されます。「発送メールを再送」は、失敗したときに1回だけ使えます。
- 記録：`shippingMails/{order_… または subscription_…}`（状態：sent / failed / skipped_test / no_email）

## 返金・キャンセル
- 返金の状態（決済済み・一部返金・返金済みと、その金額）は、Stripe の Webhook から自動で反映されます。
- 返金の判断と実行はこれまでどおり CEO が行い、この画面では行いません。
